# OpenTapUnlock iOS Application (Swift / SwiftUI + Zero Battery Drain Back Tap)

OpenTapUnlock for iOS is a production-quality, zero-trust mobile application built with modern **SwiftUI** and Apple's **Secure Enclave**. It allows you to unlock your workstation instantly by simply tapping the back of your iPhone while your device is awake and unlocked by Face ID / Touch ID.

---

## 🔋 Zero Battery Drain Architecture

To fulfill the strict requirement of **practically zero battery drain on both your mobile phone and laptop**:
1. **On the iPhone (No Accelerometer Polling)**:
   Unlike traditional Android background services that must run sensor event listeners, Apple's iOS kernel natively monitors accelerometer impulses for **Back Tap** at the silicon level using the hardware Neural Engine / motion co-processor (M-series / A-series chipsets).
   Therefore, **OpenTapUnlock does NOT run an accelerometer background loop**. Our iOS app consumes **0.00% CPU and 0.0% battery** when idle!
2. **On the Laptop (`opentapd`)**:
   The desktop daemon uses async event-driven sockets (`tokio` epoll/kqueue/IOCP) and passive low-power BLE advertising (`ADVERTISE_MODE_LOW_POWER`). It consumes zero cycles when waiting for an unlock packet.
3. **Instant Execution via Apple AppIntents**:
   When you perform a Back Tap on your phone, iOS wakes up `UnlockPCIntent` in the background for ~150ms. It checks Face ID / Touch ID lock screen status, loads your Ed25519 secret key from the **Apple Keychain**, signs the challenge in Rust via `libopentap_ffi.a`, transmits a 128-byte UDP/TCP burst over local Wi-Fi / BLE, triggers a heavy haptic vibration confirmation on your hand, and goes right back to sleep!

## 🛠️ How to Build and Link in Xcode

### 1. Compile the Rust C-ABI Static Library
```bash
cd opentap-ffi
# Compile static library for iOS device and simulator
cargo build --release
```

### 2. Open Xcode Workspace
1. Open `OpenTapUnlock/OpenTapUnlock.xcodeproj` in Xcode 15+.
2. Ensure `OpenTapUnlock-Bridging-Header.h` is configured in **Build Settings -> Objective-C Bridging Header**.
3. Link `libopentap_ffi.a` in **General -> Frameworks, Libraries, and Embedded Content**.

### 3. Enable System-Wide Back Tap in iOS Settings
1. On your iPhone, open **Settings ➔ Accessibility ➔ Touch ➔ Back Tap**.
2. Tap **Triple Tap** (or **Double Tap**).
3. Scroll down to the **Shortcuts** section and select **Unlock My Workstation**.
4. Test it! Lock your laptop, unlock your iPhone with Face ID, and perform a Triple Tap on the back of your phone!
